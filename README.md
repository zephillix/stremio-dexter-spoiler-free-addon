# Dexter Spoiler-Free Thumbnails (Stremio addon)

A fanmade Stremio addon that is made to replace all of the current spoiler-ish episode images for the shows: Dexter, Dexter: New Blood, Dexter: Original Sin and Dexter: Resurrection.

**Vibecoded by Claude.**

## Install
Please install it here: https://stremio-dexter-spoiler-free-addon.onrender.com/manifest.json

## How people find and open it
Stremio asks addons in order and Cinemeta usually answers first for the normal Dexter entry, so this addon
has its own entries (ids starting with `dxs:`, which only this addon answers):

- **Search:** typing Dexter, Dexter: New Blood (or just new blood, or Dexter New Blood), Dexter: Original Sin (or just original sin, or Dexter Original Sin) or Dexter: Resurrection (or just resurrection or Dexter Resurrection) shows results under **Dexter (Spoiler-Free)**.
- **The Discover tab:** Go on the Discover tab press the drop down and select Series -> catalog **Dexter (Spoiler-Free)**.
- **Board:** a **Dexter (Spoiler-Free)** row, where the Stremio version shows third-party catalogs.

  **Please note that if you have multiple addons that change the search categories then Dexter (Spoiler-Free) will be at the very bottom, using [Stremio Addon Manager](https://addon-manager.viren070.me) should fix this.**

The normal Dexter entry still comes from Cinemeta; only the entries above get the spoiler-free thumbnails.
Episodes still play from the viewer's own stream addons.
